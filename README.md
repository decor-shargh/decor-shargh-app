# Decor Shargh — V18.0

مبنای این نسخه: V17.1.

تغییرات V18:
- Home هر سه نقش Admin، Site Supervisor و Project Manager آمار قراردادهای جاری و تاریخی را در کارت‌ها و نمودار وضعیت لحاظ می‌کند.
- قراردادها برای هر سه پنل در دو نمای «قراردادهای خاتمه‌نیافته» و «قراردادهای خاتمه‌یافته» نمایش داده می‌شوند. جابه‌جایی فقط نمایشی است و هیچ Migration بین Collectionها انجام نمی‌شود.
- هر قرارداد جاری که همه فعالیت‌هایش 100٪ شود خودکار در نمای خاتمه‌یافته قرار می‌گیرد؛ اگر درصد فعالیت کمتر از 100٪ شود دوباره در خاتمه‌نیافته دیده می‌شود.
- Site Supervisor می‌تواند قراردادهای historicalContracts را ببیند و درصد فعالیت آنها را اصلاح کند؛ Project Manager فقط Read-only باقی می‌ماند.
- Admin همچنان می‌تواند اطلاعات قراردادهای تاریخی را ویرایش کند.
- Bottom Nav ادمین: کتابخانه حذف شده و «خروجی» جای آن را گرفته؛ کتابخانه از «بیشتر» در دسترس است.
- خروجی برای Admin و Project Manager فعال است.
- سه PDF مالی اضافه شد: خلاصه مالی، مالی ماهانه و ریز قراردادهای مالی. قراردادهای فسخ‌شده از گزارش‌های مالی حذف می‌شوند.
- کد قلم به سمت راست جداول قرارداد در تمام PDFها اضافه شد.
- در فیلتر مالی، برای هر سال دکمه «انتخاب کل سال / لغو کل سال» اضافه شد.
- Firebase Auth/Session و ساختار کاربران تغییر نکرده است.

نکته: چون دسترسی Site Supervisor به historicalContracts اضافه شده، `firestore.rules` این نسخه باید قبل از استفاده کامل Publish شود.

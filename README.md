# دکوراسیون شرق — Admin V12

اصلاحات این نسخه:
- جابه‌جایی صفحه خانه: «قراردادهای نیازمند توجه» اکنون زیر «وضعیت قراردادها» قرار گرفته است.
- بخش «پروژه‌های فعال» از صفحه خانه حذف شد تا خانه سبک‌تر و متمرکزتر باشد.
- UI موبایل فشرده‌تر شد: هدر، KPIها، پنل‌ها، کارت‌ها، نمودارها و نوار پایین جمع‌وجورتر شدند.
- لوگوی رسمی جدید جایگزین شد و آیکون‌های PWA نیز با برند نهایی به‌روزرسانی شدند.
- Cache/PWA به V12 ارتقا یافته است.
- منطق حساس V11 شامل منطق تاریخ پایان/تاریخ جبرانی و ذخیره ویرایش قرارداد با read-after-write حفظ شده است.

# Decor Shargh — Admin + Site Supervisor V14

اصلاحات این نسخه:
- پنل نقش `siteSupervisor` فعال شد و دیگر به صفحه «پنل این نقش آماده نیست» هدایت نمی‌شود.
- صفحه Home سرپرست اجرا همان داشبورد Admin را نمایش می‌دهد: KPIها، نمودار پیشرفت، وضعیت قراردادها و قراردادهای نیازمند توجه.
- صفحه قراردادهای سرپرست ساده و Quick Update است؛ ساخت/حذف/ویرایش قرارداد و افزودن/ویرایش/حذف فعالیت در دسترس نیست.
- با لمس کارت قرارداد، فعالیت‌ها مستقیم باز می‌شوند و سرپرست فقط درصد را ثبت یا فعالیت را «انجام شد» می‌کند.
- وزن و ضریب در پنل سرپرست نمایش داده نمی‌شوند.
- تاریخچه تغییر درصد برای هر قرارداد به صورت `contracts/{contractId}/history` ثبت می‌شود و فقط با زدن «تاریخچه تغییرات» بارگذاری/باز می‌شود.
- رکورد تاریخچه شامل فعالیت، درصد قبلی/جدید، کاربر، نقش، تاریخ و نوع تغییر است.
- برای جلوگیری از دستکاری ساختار فعالیت توسط سرپرست، پیشرفت سرپرست در `progressByActivity` ذخیره می‌شود و Rules فقط همان فیلدهای مجاز را برای نقش سرپرست باز می‌کنند.
- Admin همچنان دسترسی کامل قبلی را دارد و تغییر درصد Admin نیز وارد تاریخچه می‌شود.
- بکاپ V14 تاریخچه زیرمجموعه قراردادها را نیز در فایل JSON نگه می‌دارد و در Restore جدید بازیابی می‌کند.
- Firestore Rules محلی برای دسترسی محدود سرپرست به contracts و history به‌روزرسانی شده است؛ این فایل به‌صورت خودکار Deploy نشده است.

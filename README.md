# Decor Shargh — V17.0

تغییرات این نسخه:
- بایگانی قراردادهای تاریخی برای Admin اضافه شد.
- قراردادهای بایگانی در Collection جداگانه `historicalContracts` نگهداری می‌شوند.
- Import امن با فایل JSON محلی: Dry Run، بررسی کد قلم‌های تکراری، سپس تأیید نهایی.
- قراردادهای جاری هیچ‌وقت در Import overwrite نمی‌شوند.
- سرچ و فیلتر بایگانی فقط داخل خود بایگانی انجام می‌شود.
- قراردادهای بایگانی قابل ویرایش هستند و همیشه خاتمه‌یافته/100٪ باقی می‌مانند.
- آمار Home ادمین (کل/خاتمه‌یافته/نمودار وضعیت) بایگانی را هم لحاظ می‌کند.
- گزارش مالی Admin و Project Manager از قراردادهای جاری + بایگانی محاسبه می‌شود.
- نمودارها و هشدارهای اجرایی از قراردادهای جاری تغذیه می‌شوند و با بایگانی شلوغ نمی‌شوند.
- Backup شامل `historicalContracts` نیز هست.
- Auth/Session تغییر نکرده و کاربران فعلی Logout نمی‌شوند.

نکته: برای استفاده از بایگانی باید `firestore.rules` همین نسخه Publish شود.


## V17.1

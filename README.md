# Decor Shargh — Admin V15.7

تغییرات این نسخه:
- ثبت درصد و «انجام شد» در پنل سرپرست اجرا از لاگ/تاریخچه جدا شد تا خطای بخش جانبی مانع ذخیره پیشرفت نشود.
- ثبت پیشرفت سرپرست فقط progressByActivity و فیلدهای همگام‌سازی را می‌نویسد؛ وضعیت در انتظار شروع/در حال انجام/خاتمه‌یافته از روی درصدها محاسبه می‌شود.
- پیام راهنمای نصب iOS فقط یک‌بار روی همان مرورگر/دستگاه نمایش داده می‌شود.
- قرارداد متوقف همچنان بر اساس پایان اصلی و تاریخ جبرانی زمان می‌خورد؛ دلیل توقف و مدت توقف روی کارت نمایش داده می‌شود.
- زمان عادی (نه نزدیک سررسید و نه بحرانی) با رنگ سبز در همه پنل‌ها نمایش داده می‌شود.
- در نمودار پروژه‌های خاتمه‌نیافته، درصدها در یک ستون ثابت کنار میله‌ها قرار گرفتند و برچسب بحرانی/نزدیک سررسید در ستون سمت چپ آن‌ها بزرگ‌تر شد.
- قراردادهای خاتمه‌یافته همیشه به انتهای لیست قراردادها منتقل می‌شوند.
- فایل Rules شامل دسترسی کامل V15 برای سرپرست اجرا، تاریخچه، مشکلات، حضور و لاگ تغییرات است.

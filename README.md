# دکوراسیون شرق — Admin V10

اصلاحات V10:
- هر ایمیل در مدیریت کاربران فقط یک بار نمایش داده می‌شود، حتی اگر رکوردهای قدیمی تکراری وجود داشته باشند.
- تأیید، ویرایش نقش، مسدودسازی و فعال‌سازی روی همه رکوردهای هم‌ایمیل اعمال می‌شود تا وضعیت‌ها متناقض نمانند.
- کاربر مسدود دکمه «حذف» دارد؛ حذف به‌صورت امن از فهرست انجام می‌شود و حساب Auth همچنان مسدود باقی می‌ماند.
- تم تیره از سبز تیره به مشکی/گرافیتی تغییر کرد؛ رنگ طلایی برند حفظ شد.
- نسخه Service Worker و کش به V10 ارتقا یافت.

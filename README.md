# Decor Shargh — V16

نسخه V16 شامل پنل کامل مدیر پروژه و گزارش مالی مشترک است.

## پنل مدیر پروژه
- Bottom Navigation: خانه، قراردادها، گزارش مالی، خروجی.
- هدر: Decor Shargh + Project Manager Panel + تم + خروج.
- خانه: KPIهای مدیریتی، دو نمودار فعلی Admin، و دو فیلتر تعاملی «بحرانی» و «نزدیک سررسید» با تعداد.
- قراردادها: فقط مشاهده، با فیلتر نام/وضعیت و سال/ماه، بدون ساخت/حذف/ویرایش یا تغییر درصد و وضعیت.
- جزئیات قرارداد: فعالیت‌ها و درصدها به‌صورت Read-only و واضح؛ فعالیت 100٪ مشخص و کم‌رنگ است.
- مشکلات: مدیر پروژه می‌تواند مشکل باز را «انجام شد» کند و توضیح مدیریتی ثبت کند؛ متن اصلی مشکل را تغییر یا حذف نمی‌کند. توضیح مدیریتی برای Admin و سرپرست اجرا نیز قابل مشاهده است.
- تاریخچه قرارداد برای مدیر پروژه نمایش داده نمی‌شود.

## گزارش مالی
- در Admin و Project Manager فعال است.
- قراردادهای فسخ‌شده از تمام محاسبات مالی حذف می‌شوند.
- KPIها: ارزش کل، خاتمه‌نیافته، خاتمه‌یافته، بحرانی، متوقف، میانگین مبلغ، ارزش تحقق‌یافته.
- نمودار مبلغ قراردادها: در انتظار شروع / در حال انجام / متوقف / خاتمه‌یافته.
- انتخاب چند ماه از چند سال بر اساس تاریخ عقد قرارداد.

## خروجی مدیر پروژه
- PDF قراردادهای بحرانی
- PDF نزدیک سررسید
- PDF مشکلات باز
- PDF خلاصه همه قراردادها
- انتخاب چندماهه بر اساس تاریخ عقد، پیش‌نمایش قبل از خروجی، دانلود PDF و Print/Share.

## دسترسی و امنیت
- Role موجود projectManager فعال شده است.
- مدیر پروژه همه قراردادها را می‌خواند اما قرارداد، درصد، فعالیت و وضعیت را تغییر نمی‌دهد.
- فقط برای تعیین تکلیف مشکل باز، وضعیت مشکل و یادداشت مدیریتی را ثبت می‌کند.
- Firestore Rules V16 باید همراه نسخه منتشر شود.


## V16.1
- فیلترهای گزارش مالی و خروجی به‌صورت پیش‌فرض جمع‌شده و با دکمه باز/بسته می‌شوند.
- فونت کارت‌ها و مبالغ نمودار مالی بزرگ‌تر و خواناتر شد.
- هدر پنل مدیر پروژه در یک خط فشرده شد: لوگو، Decor Shargh، عنوان پنل، تم و خروج.
- Firestore Rules و داده‌ها در این نسخه تغییری نکرده‌اند.


## V16.2
- کلیک روی KPIهای صفحه خانه در هر سه پنل اکنون دقیقاً همان گروه قرارداد را نمایش می‌دهد.
- «نزدیک سررسید» فقط قراردادهای ۴ تا ۷ روز مانده، «بحرانی» فقط بحرانی/گذشته، و «میانگین پیشرفت» فقط پروژه‌های خاتمه‌نیافته را باز می‌کند.
- کلیک مستقیم روی تب قراردادها یا تغییر فیلترهای دستی، فیلتر KPI پنهان را پاک می‌کند تا تداخل ایجاد نشود.
- نمودارها و Firestore Rules در این نسخه تغییری نکرده‌اند.

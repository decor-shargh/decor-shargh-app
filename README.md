# دکوراسیون شرق — Admin V11

اصلاحات این نسخه:
- رفع مشکل ذخیره نشدن تغییرات فرم ویرایش قرارداد با تأیید read-after-write از Firestore و رفرش فوری state محلی.
- تاریخ جبرانی دیگر جای تاریخ پایان اصلی را برای بحرانی‌شدن نمی‌گیرد.
- اگر تاریخ جبرانی ثبت شده باشد، وضعیت زمانی هم‌زمان اختلاف با پایان اصلی و وضعیت تاریخ جبرانی را نمایش می‌دهد.
- عبور از تاریخ پایان اصلی، حتی با وجود تاریخ جبرانی آینده، قرارداد را بحرانی نگه می‌دارد.
- Cache/PWA به V11 ارتقا یافته است.

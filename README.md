# Decor Shargh — Admin V13.3

اصلاحات این نسخه:
- صفحه جزئیات قرارداد در موبایل فشرده‌تر و بدون بیرون‌زدگی بازطراحی شد.
- Summary بالا به مدل B تبدیل شد: مبلغ، پیشرفت و وضعیت قرارداد فشرده + وضعیت زمانی در نوار جدا.
- فقط بخش تاریخ جبرانی رنگی می‌شود: آینده سبز، گذشته قرمز، امروز طلایی/خنثی.
- کارت فعالیت‌ها دو بخشی شد؛ عنوان در ردیف کامل و وزن/ضریب کنار هم و ریزتر نمایش داده می‌شوند.
- فیلد درصد فقط از نظر عرض کوچک‌تر شد.
- روی Focus/Tap مقدار درصد Select می‌شود تا بدون پاک کردن صفر بتوان مقدار جدید نوشت.
- ثبت درصد فقط با دکمه «ثبت» انجام می‌شود (Enter نیز همان دکمه را فعال می‌کند).
- دکمه تکمیل از تیک سبز به «انجام شد» تغییر کرد و جای آن از فیلد درصد جدا شد.
- فعالیت 100٪ با خط کم‌رنگ روی عنوان و حالت انجام‌شده مشخص می‌شود.
- ترتیب دکمه‌های پایین کارت: حذف، ویرایش، انجام شد در سمت چپ؛ درصد و ثبت در سمت راست.
- منطق Firebase/Auth/Firestore و منطق حساس تاریخ/ویرایش قرارداد دست‌نخورده است.
